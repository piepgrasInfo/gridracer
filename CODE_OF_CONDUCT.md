# Code of conduct

Grid Racer follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
be welcoming, be respectful, and assume good faith - in issues, pull requests, and anywhere
else the project is discussed.

Report unacceptable behaviour to **apps@piepgras.info**. Reports are read by the maintainer
only and handled in confidence.
