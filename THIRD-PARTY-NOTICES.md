## Notes on compatibility

**Apache-2.0 and MIT components combine freely with an MIT project.** Each keeps
its own notice; anyone redistributing a build should carry those notices along,
and Apache-2.0 additionally asks that any `NOTICE` file a component ships be
kept with it.

**Logback is dual-licensed** — "either the terms of the Eclipse Public License
v1.0 … or (per the licensee's choosing) … the GNU Lesser General Public License
version 2.1". It is used unmodified and dynamically linked, so the MIT licence of
this project is unaffected. The server distribution bundle contains the Logback
jars; whoever redistributes that bundle redistributes Logback and must meet the
terms of whichever of the two licences they rely on — in practice, keep
Logback's licence notices with its jars.

**JUnit is EPL-2.0** and `testImplementation` only: it is never part of a
distributed build.

**Sentry is present but inert in a source build.** The crash-reporting endpoint
is supplied at build time and is not in this repository, so a build made from
source initialises nothing and sends nothing. See the README.

## Assets

The sound effects (`app/src/main/res/raw/*.wav`), the launcher icon set and the
Play feature graphics are generated by the scripts in [`scripts/`](scripts/)
from code in this repository — there is no third-party artwork, sample library
or font embedded in the app. The feature-graphic script rasterises text using
DejaVu Sans from the build machine's font directory; DejaVu is distributed
under the Bitstream Vera-derived DejaVu licence, which permits that use and
places no condition on the resulting image.

The MIT licence grants no trademark rights: the **name "Grid Racer" and the
icon and store artwork, as identifiers of this app**, are not licensed for
branding a redistributed build — see the README's "Name and artwork" section.
